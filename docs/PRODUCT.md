# Product behavior

DreamForge is a non-custodial Somnia Shannon application for expressing, testing and executing DreamDEX Event Contract strategies.

The application does not ask for private keys or seed phrases. A connected injected EVM wallet approves every live write.

If market history, settlement history, live-market state, executable liquidity or a required price condition cannot be verified, the relevant action remains unavailable rather than substituting mock data.
